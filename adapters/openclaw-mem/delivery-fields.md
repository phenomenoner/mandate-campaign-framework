# openclaw-mem Delivery Fields

Suggested `domain_metadata` for an `openclaw-mem` decision packet:
- `failure_cluster_id`
- `cluster_size`
- `root_cause_candidates`
- `confidence_label`
- `proposal_summary`
- `expected_outcome`
- `operator_decision`
- `followup_validation_pointer`

These stay in the adapter layer, not in the kernel contract.
