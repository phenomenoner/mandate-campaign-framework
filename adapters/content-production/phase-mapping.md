# Content-Production Phase Mapping

## Generic -> Content production
- `INTAKE` -> mandate normalization / audience framing
- `EXPLORE` -> outline generation / angle exploration
- `EVALUATE` -> outline selection / draft critique / revision scoring
- `SYNTHESIZE` -> final draft packaging
- `GATE` -> publish approval / major scope decision
- `DELIVER` -> publication-ready content packet
- `CLOSED` -> published / held / rejected / expired

## Why this matters
The mapping proves that the kernel phase machine can operate in a very different domain without importing Steamer nouns.
